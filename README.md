# 00

مستودع جاهز لاستقبال موقع ثابت مبني بـ **HTML وCSS وJavaScript**، مع إعداد نشر تلقائي على GitHub Pages عند كل تحديث لفرع `main`.

> الصفحة الحالية `index.html` مؤقتة؛ استبدلها بصفحة موقعك عند رفع الملفات.

## رفع الموقع من VS Code

### 1. تنزيل المستودع وفتحه

من الطرفية (Terminal):

```bash
git clone https://github.com/Mohamed59Nasser/00.git
cd 00
code .
```

أو استخدم **Git: Clone** من داخل VS Code، ثم افتح المجلد الذي تم تنزيله.

### 2. إضافة ملفات الموقع

- انسخ ملفات الموقع إلى جذر المجلد `00`.
- يجب أن يكون ملف البداية اسمه `index.html` وأن يوجد مباشرةً في جذر المستودع، وليس داخل مجلد إضافي.
- استبدل ملف `index.html` المؤقت الموجود حاليًا.
- ارفع مجلدات الصور وCSS وJavaScript كما هي، وتأكد من أن الروابط داخل الموقع نسبية وتعمل مع رابط GitHub Pages.
- لا ترفع كلمات مرور أو مفاتيح API أو ملفات `.env`.

### 3. حفظ التعديلات ورفعها إلى GitHub

من قائمة **Source Control** في VS Code:

1. اضغط علامة `+` لتجهيز كل التغييرات (Stage All Changes).
2. اكتب رسالة مثل `Upload website`.
3. اضغط **Commit** ثم **Sync Changes / Push**.

ويمكن تنفيذ الخطوات نفسها من Terminal داخل VS Code:

```bash
git add .
git commit -m "Upload website"
git push
```

## تفعيل النشر على GitHub Pages (مرة واحدة)

1. افتح المستودع على GitHub.
2. انتقل إلى **Settings → Pages**.
3. في **Build and deployment → Source** اختر **Deploy from a branch**.
4. اختر الفرع `main` والمجلد `/(root)` ثم اضغط **Save**.
5. بعد كل Push ناجح إلى `main` سيُحدَّث الموقع تلقائيًا، ويمكن متابعة النشر من تبويب **Actions**.

بعد نجاح النشر سيكون الموقع متاحًا على:

**https://mohamed59nasser.github.io/00/**

## تجربة الموقع محليًا

يمكن فتح `index.html` مباشرةً في المتصفح، أو تثبيت إضافة **Live Server** المقترحة في VS Code ثم اختيار **Open with Live Server**.

## إذا كان المشروع ليس موقعًا ثابتًا

إعداد النشر الحالي مخصص للمواقع الثابتة فقط. إذا كان المشروع يستخدم React أو Vite أو Next.js أو Node.js أو قاعدة بيانات، فيجب تعديل خطوات البناء والنشر بما يناسب المشروع قبل رفعه.
