إدارة بيانات عملاء الوساطة العقارية

التطبيق الكامل يحتاج إلى خادم هذا المشروع مبني بـ Next.js ويعتمد على واجهات API وقاعدة PostgreSQL أو Google Sheets. GitHub Pages يستضيف الملفات الثابتة فقط، لذلك لا يمكنه تشغيل لوحة إدارة العملاء أو حفظ البيانات. لم يتم إعداد رابط Google Sheet أو إضافة أي بيانات تجريبية.
  • إدارة بيانات المشترين والبائعين
  • البحث والتصفية حسب العقار والمنطقة
  • التصدير إلى Excel
  • ربط Google Sheets اختياريًا من الخادم
